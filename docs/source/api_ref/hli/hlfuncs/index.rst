``hlfuncs`` - High-level abstraction modules
=============================================

.. code-block:: python

    from xoa_driver import hlfuncs

``hlfuncs`` is a package that collects several modules for high-level abstraction functions:

    :maxdepth: 1

    mgmt - Resource management functions <mgmt>
    headers - Predefined headers <headers>
    config_io - Port configuration functions <config_io>

    cmis - CMIS functions <cmis/index>
